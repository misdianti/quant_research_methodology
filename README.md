# 🦔 PDE — Porcupine Double Edge

A machine learning pipeline for directional trade signal generation on **XAUUSD (Gold Spot)**, built on H1 OHLCV data.

---

## Overview

PDE identifies high-probability setups at swing structure extremes and predicts whether price, upon revisiting those levels, is more likely to break through (long) or reject (short). The signal is generated by an XGBoost classifier trained on price structure and momentum features, filtered by a probability threshold tuned on a held-out validation period.

The pipeline is divided into three stages, each in its own notebook:

| Notebook | Description |
|---|---|
| `01_feature_engineering.ipynb` | Swing structure detection, technical indicator computation, entry trigger scanning, and trade labeling |
| `02_model.ipynb` | XGBoost training, walk-forward validation, threshold tuning, and trading performance evaluation |
| `03_simulation.ipynb` | Out-of-sample simulation, performance analysis, and equity curve |

## Methodology

### Lookahead Bias Prevention

Features are snapshotted from the candle **prior to entry** (j-1), not at the trigger candle itself. This ensures no future price information leaks into the feature vector at prediction time.

### Temporal Data Splits

| Split | Period | Purpose |
|---|---|---|
| Train | 2015 — 2020 | Model development |
| Dev test | 2021 | Threshold and hyperparameter validation |
| Holdout | 2023 | Out-of-sample evaluation pre-deployment |
| Forward validation | Jan 2025 — present | Live out-of-sample; no retraining after this point |

### Model Training

- **Algorithm**: XGBoost (`binary:logistic`, optimized for AUCPR)
- **Hyperparameter search**: `RandomizedSearchCV` over 80 iterations, evaluated with `TimeSeriesSplit` (5 folds) to preserve temporal order
- **Threshold tuning**: Probability threshold selected on holdout set by maximizing Sharpe; not re-optimized on forward data

### Walk-Forward Validation

The model is retrained quarterly using all data available up to that quarter, then evaluated on the following quarter. This simulates realistic deployment: the model always trains on the past and predicts the immediate future.

## Feature Engineering

| Category | Features |
|---|---|
| Swing structure | Deviations from swing top across prior 3 candles |
| Momentum | MACD, MACD signal, MACD histogram (current + 3 lags) |
| RSI | RSI-14 and RSI-5 (current + 3 lags each) |
| Trend | EMA spreads: MA20/50/100/200 cross-combinations |
| Volatility | Bollinger Band distances (upper, middle, lower) |
| Price action | High/low/close/body deviations across 5 prior candles; candle body-to-range ratio |
| Context | Distance from entry to all-time high |
| Calendar | Hour, day of week, month |

## Performance — Forward Validation (Jan 2025 — Present)

> Out-of-sample period. Model was not retrained or adjusted after January 2025.

| Metric | Value |
|---|---|
| Win Rate | 56.5% |
| Profit Factor | 1.30 |
| Expectancy | 3.27 points/trade |
| Annualized Sharpe | 2.31 |
| Max Drawdown | 4,050 points |
| Trades/Year | ~307 |

**Notes on interpretation:**
- Annualized Sharpe is partly a function of trade frequency (~307/year); per-trade Sharpe is 0.13.
- The 2025 forward period coincides with a strong gold bull run. Long-side performance may be regime-dependent. Short-side performance is not separately reported here.
- Profit Factor of 1.30 is a baseline figure. The primary value of this iteration is establishing a reproducible evaluation framework, not claiming optimal performance.
